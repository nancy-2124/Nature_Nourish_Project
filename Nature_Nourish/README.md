# Nature Nourish

Nature Nourish is a static HTML/CSS/JavaScript website focused on sustainable eating.

Live Demo: https://naturenourish-theta.vercel.app/
Github Repository: https://github.com/nancy-2124/Nature_Nourish_Project/edit/main/Nature_Nourish/

## Pages
- `index.html` — Home page
- `about.html` — About page
- `resource.html` — Sustainability resources and food impact calculator
- `food.html` — Recipe page with expandable recipe details
- `recipes.html` — Additional recipe page
- `quiz.html` — Multi-level sustainability quiz
- `styles.css` — Main stylesheet
- `script.js` — Quiz, recipe toggle, and food-impact calculator logic

## Run
Open `index.html` in a browser.

The project uses external image/CDN URLs in some pages, so an internet connection may be required for those images/icons to load.
